# v2 Test Infrastructure Plan

## Phase 1 — Unit Tests

Runner: Vitest
DOM: jsdom
Component: @testing-library/react
Coverage: @vitest/coverage-v8

Setup files:
- package/vitest.config.ts
- package/src/test/setup.ts

Target modules and priority order → [agents/base/unit.md](../base/unit.md)

## Phase 2 — E2E Tests

Runner: Playwright
Config: playwright.config.ts (repo root)
Test directory: `test/e2e/`

Target flows and priority order → [agents/base/e2e.md](../base/e2e.md)

## Phase 3 — GitHub Actions Pipeline

Shipped as two separate workflows, not the single `test.yaml` originally planned:

- `.github/workflows/integration.yml` — runs `cd package && yarn test:integration`
- `.github/workflows/e2e.yml` — runs Playwright

Trigger: pull_request, and push to the tracked branches.

Not covered by CI: unit tests, typecheck, lint, and build. Unit tests run only in
the husky `pre-commit` hook (`yarn vitest run --changed`).
